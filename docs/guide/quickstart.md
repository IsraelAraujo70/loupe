# Quickstart

Install Rust and Node, then build the library:

    cargo build --release

Start the web client from the `web` folder:

    npm install
    npm run dev

Open the planner in the browser and add your first recipe. A recipe needs a
name, the number of servings it feeds, and at least one ingredient line such
as `200 g flour` or `1 cup milk`.

## Next steps

- Scale a recipe to the number of guests.
- Keep the pantry stock up to date, with expiry dates.
- Try the crème brûlée sample from the catalog.
