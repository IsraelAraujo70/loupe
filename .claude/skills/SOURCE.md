# Where these skills come from

- `gpui-kit/` and `gpui-kit-design-guides/`: copied from https://github.com/longbridge/gpui-kit (`skills/`, commit 6808964, Apache-2.0). They describe gpui-kit 0.9.1; Loupe pins 0.9.0, so check an API against the sources when in doubt. The Design Guides are normative for every Loupe screen.
- `gpui-*` (actions, async, code-quality, elements, entities, fundamentals, init, patterns, styling, testing, troubleshooting): copied from https://github.com/cnwzhu/gpui-skills (commit 393a3da, README states Apache-2.0). They describe upstream GPUI; check names against gpui-kit 0.9.0.
